# Microsoft 365 & Copilot Administration – Hands-on Lab

## 📌 Project Overview

This project is a hands-on Microsoft 365 administration lab designed
to demonstrate practical skills related to Microsoft 365, Microsoft
Entra ID, SharePoint, Microsoft Purview, and Microsoft Copilot agents.

The project simulates an IT environment for a fictional company called
Contoso IT Services.

---

## 🎯 Project Objectives

- Manage Microsoft 365 users and groups
- Configure Microsoft Entra ID
- Implement basic identity and security controls
- Create and manage a SharePoint knowledge base
- Configure SharePoint permissions
- Explore Microsoft Purview data governance
- Configure sensitivity labels and DLP concepts
- Create an IT Helpdesk Copilot agent
- Configure agent knowledge sources
- Test agent responses
- Apply agent access and governance concepts

---

## 🏢 Business Scenario

Contoso IT Services wants to improve its internal IT support process.

Employees frequently ask questions about:

- Password resets
- Multi-factor authentication (MFA)
- Microsoft 365
- VPN troubleshooting
- Security procedures

To solve this problem, an internal IT Knowledge Base and
AI-powered IT Helpdesk Agent were created.
